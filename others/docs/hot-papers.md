# Hot Papers

Weekly view for recent Agent Worlds papers. The Static Explorer homepage shows
an indexed strip from this table; this document keeps the fuller weekly view.

Curated resources are the entries in the Resource Index and main README.

- Updated: 2026-06-14
- Cadence: weekly
- Source scope: recent arXiv papers with Agent Worlds evidence
- Catalog status: indexed or tracking

## Inclusion Criteria

A paper appears in this weekly view when there is clear evidence for its world
role, observation/action surface, verifier or reward, reset or replay support,
trajectory access, sandbox or safety boundary, and first-party source. The
status column separates papers already indexed in the main catalog from papers
tracked for future inclusion. Main-index entries require first-party evidence
and complete catalog metadata.
